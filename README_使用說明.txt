庚辰空調 V5｜前台優化＋V4工程後台（本機版）

1. index.html 是品牌官網，admin.html 是工程管理後台。
2. 不使用 LINE、Email 或雲端；表單僅存於填寫者目前瀏覽器，不能跨裝置傳至店家。
3. 管理後台同樣僅有本機瀏覽器的資料，正式預約請致電確認。
4. 服務展示區是示意視覺，不代表真實施工案例；未來可換上已取得使用授權的實際照片。
5. 後台不具有正式驗證機制，請勿公開存放客戶個資。定期使用 JSON 匯出備份，勿清除網站資料。
6. 建議以同一個網址/來源開啟兩個頁面；直接開啟獨立 HTML 檔時，不同瀏覽器的 localStorage 可能不共享。
